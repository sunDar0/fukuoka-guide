# 후쿠오카 여행 가이드 🇯🇵

후쿠오카 여행을 위한 인터랙티브 웹 가이드입니다. 여행 날짜·인원·이동 수단을 고르면 일정, 예산, 관광지 정보를 한눈에 볼 수 있습니다.

## 주요 기능

### 맞춤형 여행 플래너
- 여행 날짜, 인원(성인/아동/영유아), 이동 수단 입력으로 일정 생성
- 이동 수단 3종 × 2~5박, 큐레이션된 일정 12개
  - 대중교통: 하카타·텐진 거점 + 대중교통으로 가기 좋은 근교
  - 렌터카: 공항 픽업~반납 전 일정 렌터카
  - 렌터카+대중교통: 시내는 대중교통, 근교 가는 날만 렌터카
- 6~7박은 5박 일정을 쓰고, 마지막 날을 귀국일에 맞추며 남는 날은 자유 일정으로 안내
- 계절 대체: 출발 월이 아니라 그 일차의 실제 날짜 월에 맞춰 크리스마스 마켓·매화·벚꽃·단풍·등나무 일정으로 바꿔 보여줌
- 아이·노부모 동반 메모를 일정 항목마다 표시
- 예산 계산기 (숙박/교통/식비/관광/쇼핑). 렌터카는 대여 일수와 대수(5명당 1대) 기준으로 계산
- 월별 날씨(1991~2020 평년값)와 짐 싸기 팁
- 공유 링크 생성 (`?s=출발일&e=귀국일&a=성인&c=아동&i=영유아&m=transit|car|mixed`)

### 인터랙티브 지도
- Leaflet 기반 명소 62곳 + 맛집 25곳 + 숙소 25곳
- 9개 지역별 필터링 (하카타, 텐진/나카스, 다자이후, 후쿠오카 시내, 이토시마, 키타큐슈, 유후인, 벳푸, 아사쿠라). 지역 필터는 맛집·숙소 레이어에도 적용
- 레이어 토글 (관광지/맛집/숙소 각각 표시/숨기기)
- 지역별 추천 경로 보기 (Nearest Neighbor 알고리즘, 직선 거리 기준)
- 명소 검색

### 맛집 가이드
- 25개 맛집 (라멘, 모츠나베, 교자, 야키토리, 해산물, 카페, 우동, 카레, 향토음식)
- 카테고리별 필터링, 대표 메뉴·가격대·영업시간
- 맛집은 하카타·텐진/나카스·후쿠오카 시내에만 있음

### 교통 가이드
- 공항→시내 이동 수단 비교 (지하철, 국제선↔하카타역 버스, 국제선↔텐진 특급버스, 택시 등)
- 교통 패스 5종 비교 (투어리스트 시티패스, SUNQ, JR 북부규슈 레일패스 등)와 패스가 이득인지 판단하는 기준
- 렌터카 이용 안내 (국제운전면허증, 카시트)
- 주요 지역 간 이동 방법 6구간 (시간/비용/설명)

### 숙소 가이드
- 25개 숙소 (호텔/료칸/게스트하우스)
- 유형별/예산별 필터링 (절약형/중급/프리미엄)
- 시설 특징, 근처 관광지 연결 정보

### 관광지 사진
- 로컬 `images/` 폴더의 명소 사진 42장 (명소 62곳 중). 사진이 없는 항목은 이미지 영역을 숨김

### 오프라인 지원 (PWA)
- Service Worker 기반 오프라인 캐싱
- 모바일 홈 화면에 앱으로 설치 가능

### 모바일 최적화
- 지도 페이지: 1024px 이하에서 바텀시트 UI (탭으로 접기/펴기, 드래그), 결과가 나오면 시트 자동 펼침
- 플래너: 하단 고정 섹션 내비게이션, 좁은 화면용 카드 배치
- 터치 대상 44px 보장

## 기술 스택

| 구분 | 기술 |
|------|------|
| 마크업 | HTML5 |
| 스타일 | CSS3 (다크 테마, 글래스모피즘) |
| 스크립트 | Vanilla JavaScript (ES6+) |
| 지도 | Leaflet.js v1.9.4 + MarkerCluster |
| 차트 | Chart.js |
| 이미지 | 로컬 파일 (`images/`) |
| 폰트 | Noto Sans KR (Google Fonts) |
| 타일 | OpenStreetMap |
| PWA | Service Worker + Web App Manifest |

빌드 도구나 npm 패키지 없이 순수 정적 파일로 구성되어 있습니다.

## 프로젝트 구조

```
fukuoka-guide/
├── index.html      # 메인 여행 플래너 페이지
├── map.html        # 인터랙티브 지도 페이지
├── style.css       # 공통 스타일시트
├── data.js         # 명소·맛집·숙소·교통 데이터
├── planner.js      # 플래너 로직 + 날씨·예산 기본 데이터 + 일정 12개
├── map.js          # 지도 + 경로 + 레이어 + 바텀시트
├── sw.js           # Service Worker (오프라인 캐싱)
├── manifest.json   # PWA 매니페스트
├── images/         # 명소 사진
├── icon-192.svg    # 앱 아이콘 (192x192)
└── icon-512.svg    # 앱 아이콘 (512x512)
```

명소 큐레이션·일정 설계·화면 점검을 돕는 Claude Code 하네스(에이전트·스킬)가 `.claude/` 에 있습니다. 진입점은 `CLAUDE.md` 입니다.

## 실행 방법

별도의 설치 과정 없이 정적 파일 서버로 실행할 수 있습니다.

```bash
# Python
python3 -m http.server 8000

# Node.js
npx http-server

# 브라우저에서 http://localhost:8000 접속
```

같은 와이파이의 휴대폰에서는 `http://<맥 IP>:8000` 으로 접속합니다.

정적 파일을 바꾼 뒤에는 `sw.js` 의 `CACHE_NAME` 을 올려야 기존 방문자에게 반영됩니다. 로컬에서 옛 화면이 보이면 탭을 모두 닫고 다시 열거나, 개발자 도구에서 Service Worker 를 해제하세요.
